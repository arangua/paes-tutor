# 📋 Aclaración Legal y Ética: Uso de Contenido de DEMRE

## ✅ No Hay Problema de Pago

### ¿Por qué no hay que pagar?

1. **DEMRE es una institución pública:**
   - DEMRE (Departamento de Evaluación, Medición y Registro Educacional) es una institución pública de Chile
   - Los exámenes PAES son publicados de forma **gratuita y pública** en su sitio web oficial
   - Cualquier persona puede acceder a estos PDFs sin costo

2. **Contenido público:**
   - Los PDFs de exámenes oficiales están disponibles públicamente en:
     - https://demre.cl/publicaciones/
   - No requieren registro, suscripción ni pago
   - Son recursos educativos públicos para estudiantes

3. **No estamos usando una API de pago:**
   - No estamos accediendo a una API comercial
   - Estamos accediendo a contenido público disponible en el sitio web
   - Es similar a cuando un navegador descarga una página web

## 🔍 ¿Qué Hace Nuestra Aplicación?

### Web Scraping Ético

Nuestra aplicación:

1. **Accede a contenido público:**
   - Solo accede a páginas públicas de DEMRE
   - No requiere autenticación ni credenciales especiales
   - No accede a información privada o restringida

2. **Respeta el sitio:**
   - Implementa rate limiting para no sobrecargar el servidor
   - Usa User-Agent apropiado
   - No hace scraping agresivo o masivo

3. **Propósito educativo:**
   - El contenido se usa para ayudar a estudiantes a practicar
   - No se redistribuye comercialmente
   - Se mantiene dentro del contexto educativo

## 🛡️ Protecciones Implementadas

Nuestra aplicación incluye:

1. **Validación de dominio:**
   - Solo permite acceder a `demre.cl`
   - Previene acceso a otros sitios (protección SSRF)

2. **Rate limiting:**
   - Limita la frecuencia de peticiones
   - Previene sobrecarga del servidor de DEMRE

3. **Autenticación:**
   - Solo usuarios autenticados pueden usar esta funcionalidad
   - Previene uso anónimo o abusivo

4. **Manejo de errores:**
   - Respeta los errores del servidor
   - No intenta forzar acceso a contenido restringido
